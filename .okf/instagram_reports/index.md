# Instagram Reports Infrastructure

The Instagram report section provides comprehensive analytics dashboards for posts from tracked Instagram profiles, including engagement metrics, temporal intelligence, and PDF report generation.

## Components

- [Controller](controller.md) - InstagramTopicController handling show, entries_data, and pdf actions
- [Views](views.md) - Dashboard views and PDF templates
- [Aggregator Service](aggregator_service.md) - Main data aggregation service
- [Instagram Services](instagram_services.md) - Instagram API integration services
