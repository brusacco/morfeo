# Digital Media Reports Infrastructure

The digital media report section provides comprehensive analytics dashboards for web articles (entries) from monitored news sites, including sentiment analysis, temporal intelligence, and PDF report generation.

## Components

- [Controller](controller.md) - TopicController handling show, pdf, comments, history, and entries_data actions
- [Views](views.md) - Dashboard views and PDF templates
- [Aggregator Service](aggregator_service.md) - Main data aggregation service
- [PDF Service](pdf_service.md) - PDF generation service
