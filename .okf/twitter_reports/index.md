# Twitter Reports Infrastructure

The Twitter report section provides comprehensive analytics dashboards for tweets from tracked Twitter profiles, including engagement metrics, temporal intelligence, and PDF report generation.

## Components

- [Controller](controller.md) - TwitterTopicController handling show, entries_data, and pdf actions
- [Views](views.md) - Dashboard views and PDF templates
- [Aggregator Service](aggregator_service.md) - Main data aggregation service
- [PDF Service](pdf_service.md) - PDF generation service
- [Twitter Services](twitter_services.md) - Twitter API integration services
