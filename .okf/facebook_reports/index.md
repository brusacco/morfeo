# Facebook Reports Infrastructure

The Facebook report section provides comprehensive analytics dashboards for Facebook posts from tracked Pages, including engagement metrics, sentiment analysis, temporal intelligence, and PDF report generation.

## Components

- [Controller](controller.md) - FacebookTopicController handling show, entries_data, and pdf actions
- [Views](views.md) - Dashboard views and PDF templates
- [Aggregator Service](aggregator_service.md) - Main data aggregation service
- [PDF Service](pdf_service.md) - PDF generation service
- [Facebook Services](facebook_services.md) - Facebook API integration services
